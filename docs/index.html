Shorts Batch Uploader

개인 개발자가 자신의 채널에 세로형 짧은 영상을 일괄 업로드하기 위해 만든 명령줄 도구입니다.

이 도구는 무엇인가요? What this tool is

Shorts Batch Uploader는 운영자의 PC에 있는 로컬 폴더에서 세로형 짧은 영상(mp4)을 읽어, YouTube Data API v3를 통해 운영자 본인의 YouTube 채널에 업로드하는 개인용 명령줄(CLI) 도구입니다.

  • 영상 파일은 로컬 폴더에서 읽습니다.
  • 제목, 설명, 태그는 CSV 파일에서 읽습니다.
  • 필요하면 예약 공개 시각(publishAt)을 지정할 수 있습니다.
  • 그래픽 화면 없이 터미널에서만 실행됩니다.

누가 사용하나요? Who can use it

이 도구는 운영자 본인만 사용합니다. 배포하지 않으며, 일반에 공개된 서비스가 아닙니다. 타인의 계정이나 채널에 접근하지 않습니다.

접근하는 Google 사용자 데이터 Google user data accessed

이 도구가 요청하는 OAuth 범위(scope)는 다음 하나뿐입니다.

  • https://www.googleapis.com/auth/youtube.upload - 운영자 채널에 영상을 업로드하는 권한

다음 데이터는 읽지도, 저장하지도 않습니다.

  • 시청자 데이터(구독자, 시청자 정보 등)
  • 댓글
  • 분석(Analytics) 데이터
